# Ya koi commamd batao jo me antigravity terminal ko du or wo output de wo me yaha paste kar du, koi bhi confidential information yaha nahi ani chahiye

# Option 1: Git Bash / VS Code Terminal (Recommended)

Bash

 git ls-files | grep -v -i -E "(\.env|key|secret|token|pass|credential|cert|keystore)" 

# Option 2: Windows PowerShell

Agar aap standard Windows PowerShell use kar rahe hain:

PowerShell

 git ls -files | Where-Object { $_ -notmatch '(?i)(\.env|key|secret|token|pass|credential|cert)' }

 100% Safe: .env , API secret keys, certificates aur passwords wali files ko list se pehle hi filter kar degi.

# 2. KBC Games ko "Addictive" Banane ke 5 Psychological Hooks
 
Lifelines ka Chakkar:
 
 50:50 (Do galat options gayab).
 
 AI Expert / Ask the Guru (ChatGPT-powered mini explanation).
 
 Time Freeze (Timer ko 30 seconds ke liye rok dena).
 
 Addiction loop: Free users ko game me har bar sirf 1 lifeline milegi; extra lifelines lene ke liye wo points kharch karenge ya daily tasks pure karenge.

Question 5 aur Question 10 par "Safe Padav". Agar Question 12 par answer galat hua, toh player seedha Question 10 ke points par gir jayega. Ye fear-of-losing player ko dobara khelne par majboor karta hai.

KBC ka asli jadoo uski tick-tick wali ghadi, heartbeat sound, aur dramatic light effects me hai. Sahi answer par celebration sound aur galat par drop sound adrenaline pump karta hai.
 
1v1 Live Hot-Seat Battle:
 
Do live players ek hi time par same 10 sawal solve karenge. Jisne kam time me sahi jawab diya, wo match jeetega aur opponent ke trophies le jayega (Clash Royale / Ludo King style).
